# 评审演示操作单

## 开场前
1. 双击根目录“启动自在弈境.cmd”，打开http://127.0.0.1:4318/。线下演示优先使用本机地址。
2. 在“备份与恢复”下载完整备份。不要为演示覆盖本人原有英雄池或导入虚构战绩。
3. 若展示同学账号，取得其同意并隐藏账号标识；更推荐单独的演示账号，只填写确实会用的英雄，不填写编造场数。
4. 分享前双击“分享自在弈境.cmd”，从data/public-site/PUBLIC_URL.txt复制当时的新地址。手机关闭Wi-Fi，用移动数据打开一次；校园网再测一次。这两项当前需要本人操作，代理访问不能替代。
5. 提前打开已交付视频，确认本机可以播放。不要现场安装依赖、更新版本或启用未经测试的模型。

## 6分钟主线
| 时间 | 操作 | 口述重点 |
|---|---|---|
| 0:00—0:40 | 首页→英雄图鉴→搜索赵怀真→查看来源 | 全局资料只是输入；综合梯度和分段三率不是同一个统计口径 |
| 0:40—1:30 | 我的英雄池→查看一位本人已登记英雄→刷新核对 | 未知指标允许留空；截图OCR需人工核对；不是官方账号同步 |
| 1:30—2:40 | 阵容备战→找到“开始教练推演”区域→为一个固定分路指定我自己→勾选仅用已登记英雄池→推演 | 这是固定分路成员约束模式；展示候选理由及对手回应是假设 |
| 2:40—3:50 | 逐手BP→开始新演练→双方人工选择→选诸葛亮并后续补中路或打野→查看分路→尝试人工调整 | 展示另一条摇摆位流程；不声称当前联合使用上一模式全部约束；只有完成本手才更新 |
| 3:50—4:30 | 体系练习→选择实际可用的1—3名成员→看分工与缺口 | 人数不足五人也可用，不能把缺少的队友当真实好友填满 |
| 4:30—5:20 | 打开本套材料的BP评测报告→说明四组对照及边界 | 24构造局面+1边界；约束生效不等于实战胜率更高 |
| 5:20—6:00 | 展示源码、真实Prompt链和复现报告 | 人类纠错如何改变实现；已验证与待验证分别说清 |

如果英雄池为空，先用本人实际常用英雄建立记录；不要照着评测的构造选手填假战绩。若当前不便披露，直接展示已录视频，并说明是历史录屏。

## 故障处理
- 外部数据失败：保持界面原来的缺失/旧缓存标签，解释同查询缓存边界；打开有明确日期的录像或材料，不把录像冒充实时数据。
- 公网断开：本机演示切回127.0.0.1；远程演示改播放视频。电脑断电或睡眠时，本机运行的公网服务不能继续在线。
- 推荐未完成：保留已完成层数与预算提示，不口头补出不存在的推荐。
- OCR未安装：改用手工登记真实字段，说明该流程是可选本地依赖。
- 模型复盘：当前没有真实配置与专项训练，只展示证据整理流程，不当场承诺自动专业分析。

## 上台前必须自己练一次
按上述顺序计时，讲出每一步为何存在。不会解释的参数先查“答辩问答”，不要只背产品名。让一位同学打断提问，训练在30秒内回答能力边界。
