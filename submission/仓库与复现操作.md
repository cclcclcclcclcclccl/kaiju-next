# 评审仓库与运行

本地ZIP是整理好的材料副本，不能替代赛题所要求的GitHub/Gitee仓库链接。仓库尚未代为创建或上传。

## 保留完整历史上传

在GitHub或Gitee创建一个空仓库（不要先添加README）。本项目已经有真实历史，不要重新git init后只提交一次。

可以在当前项目执行以下命令，替换 `<你的仓库地址>`：

```powershell
git remote add origin <你的仓库地址>
git push -u origin HEAD:main
```

若平台要求登录，使用你自己的账号完成。设置Public，或按比赛规则授予评委访问权限。退出登录后打开链接，核查README、提交历史、源代码、视频、PDF和对话材料是否可见。

## 只有ZIP时恢复历史

解压后，在submission目录的上一级执行：

```powershell
git clone submission/开局NEXT-history.bundle kaiju-review
cd kaiju-review
git log --oneline -10
```

此方式恢复已提交源码和原始提交历史。然后为恢复出的仓库添加远程地址并推送。Git bundle不含个人数据库或密钥。

## 评委复现

前提：Node.js 24.16或更新的Node 24、npm、首次下载依赖的网络。

```powershell
npm ci
npm run build
npm start
```

打开 http://127.0.0.1:4318 。Windows日常使用也可双击start-kaiju.cmd，自动准备后后台运行。电脑重启后需要再次启动。

核心功能无需模型密钥。OCR在新机器上另外需要Python并执行npm run ocr:setup。第三方统计和图片需要网络；公开接口不可用时应看到明确错误或同查询旧缓存，不能期待离线得到最新统计。模型复盘尚未配置，不应在评审中声称它已经训练或自动理解整局。

本轮37秒复现是在预装Node/npm、已有依赖缓存的本机新目录完成，不包含安装操作系统、OCR、模型开户或所有外部请求。
