# 评审仓库、历史恢复与运行

公开仓库：https://github.com/cclcclcclcclcclccl/kaiju-next

评委优先使用该仓库，保留完整提交历史。不要重新 git init 后只提交一次。

```sh
git clone https://github.com/cclcclcclcclcclccl/kaiju-next.git
cd kaiju-next
npm ci
npm run build
npm start
```

运行环境为 Node.js 24.16 或更新的 Node 24、npm。打开 http://127.0.0.1:4318 。原有账号数据库不在仓库中，新机器首次运行创建自己的空数据库。

离线历史备份位于 `submission/release-v0251/开局NEXT-v0.25.1-history.bundle`，可以恢复源码和历史：

```sh
git clone 开局NEXT-v0.25.1-history.bundle kaiju-review
cd kaiju-review
git log --oneline -10
```

最终发布的 ZIP 是提交文件副本，Git bundle 和 GitHub 仓库保留历史。不要使用 2026-10-18 的旧包替代当前版本。

核心图鉴、BP、个人记录无需模型密钥；外部公开统计读取需要网络。OCR 新机器另需 Python 和 `npm run ocr:setup`，当前没有配置模型复盘或执行专项训练。

固定网站运行方案见 `deploy/README.md`、Dockerfile；当前执行零新增付费方案，付费配置仅存为技术参考。GitHub Actions 已通过 Linux 测试、构建、容器启动、注册及重启持久化检查；这不等于已有长期在线的云服务。

新版视频含 135 秒真实历史协作回看，不冒充现场输入生成。提供的赛事正文与实际赛项名称有差异，报名信息、截止时间、文件限制和协作演示形式仍以个人中心为准。
