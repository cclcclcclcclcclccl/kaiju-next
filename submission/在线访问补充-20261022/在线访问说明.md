# 固定在线体验入口（v0.26.1）

固定网址：https://cclcclcclcclcclccl.github.io/kaiju-next/

这是实际可交互的软件入口，无需评委安装 Node、下载源码、注册账号或等待作者电脑开机。GitHub Pages 免费托管公开前端；未购买服务器、域名或 API。站点依赖 GitHub Pages 平台可用性和访问者网络，不承诺所有运营商永远可达。

## 功能与数据范围

- 133 位英雄图鉴、技能资料与本地图标；四个已取得公开分段的统计和梯度；皮肤、出装和对局时长等已收录数据。
- 手动双方 BP / 人机 BP、浏览器 Worker 搜索、摇摆分路、体系练习与个性化推荐使用既有算法，不需要模型 API。
- 英雄池、玩家档案、备战卡、手记、手动复盘和系列赛存档保存在访问者当前浏览器的 IndexedDB；浏览器不同、设备不同不会自动同步。清除网站数据会删除记录，支持完整备份导出/恢复。
- 公开资料仅从明确允许的公开缓存目录导出；767 个查询结果保留来源 URL、原始 SHA-256、查询日期及真实获取时间。默认 2026-10-13 完整批次，其他日期按实际收录情况查询。没有将历史批次改成当前日期，没有生成虚构统计或账号数据。
- 未部署账号好友联机、服务器 OCR、后台自动抓取及外部 AI 视觉模型。相关页面明确说明限制；不会伪造成功或声称已完成专项模型训练。完整 Node 后端保留在源码交付中。

## 可复现构建

先 `npm ci`。Windows PowerShell：

```powershell
$env:ZIZAI_REVIEW_BUILD='1'
npm run build
node scripts/player/verify-review-artifact.mjs
```

生成 `dist-review/`，以 `/kaiju-next/` 为站点路径发布。清除该环境变量后 `npm run build` 仍构建原完整服务端版到 `dist/`。不能用普通构建替换 Pages 构建。

`.github/workflows/pages.yml` 在 main 更新后执行核心测试、构建、公开数据校验和 Pages 发布。公开快照已纳入版本控制，CI 不依赖作者电脑上的 data 目录。

`scripts/player/export-review-data.mjs` 仅在作者维护数据时使用；读取明确的公开缓存目录，重新核对原始数据 SHA-256 并重新解析，再生成发布索引。对缺失查询明确拒绝，不跨日期、分段或英雄补值。不导出私人数据库、游戏账号、令牌、好友关系或邀请码。

## 验证

119 项现有核心测试通过。静态服务测试完全没有 `/api` 后端：主要页面、图片子路径、英雄池刷新保留、两个标签页冲突检测、不同浏览器隔离、档案、备份恢复、手动复盘、蓝方手动禁用后红方真实 Worker 计算、移动端布局均已检查。构造测试记录只在隔离浏览器中使用，不计入真实玩家试用。

测试记录见 `evidence/online-v0261/`。实际公网检查单独记录在 `public-verification.json`；部署记录以该文件及 Actions 为准。验证不等于跨全国网络可用性保证。
