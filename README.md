# 衡局 HENGJU · 游戏经济规则反例实验室

衡局把明确的游戏经济设计意图转成可执行约束，搜索违反约束的操作路径，逐步回放资源变化，并对照检查参数修改。

参赛者：蔡晨霖，西安交通大学人工智能 2501 班。参赛项目：用户所述传智杯 AI 创新应用挑战赛；所给正文赛项名称为全国高校 Vibe Coding 开发挑战赛，最终对应关系和日期仍待官方核实。

## 当前可用版本

2026-10-11，v0.2：可视化建立资源和动作，声明必须保留的正常玩法，搜索并回放反例，对照修复对玩法的影响，保存规则和历史快照，导出含完整输入的报告与可独立核验的实验凭证。示例库的三个场景均为合成案例。第一次使用请阅读 [参赛者检查指南](docs/07-first-review-guide.md)。

文字建模适配器已实现，可通过兼容 chat/completions 的模型服务生成带数值来源的候选。当前没有配置真实模型密钥，未完成商业模型调用或质量评测；接口协议使用本机模拟服务验证。确定性实验流程不需要密钥。

该版本不是最终参赛成品。尚缺真实设计者试用、实用价值与竞品差异验证、三个完整核心 AI 迭代链、演示视频、最终技术 PDF、远程评审仓库和正式提交。

## 快速运行

环境：Node.js 24.16.0 或更新的 Node 24，npm。本轮使用 Windows、Node v24.16.0、npm 11.13.0。首次安装需要访问 npm 软件源。

在仓库根目录运行：

```powershell
npm ci
npm run build
npm start
```

打开 **http://127.0.0.1:4318**。无需数据库安装、模型密钥或登录。Windows 也可双击根目录的 start-hengju.cmd；该脚本检查 Node，必要时安装依赖，并构建后启动。

开发模式：npm run dev，打开 http://127.0.0.1:4317。

停止服务：在启动终端按 Ctrl+C。默认数据文件为 data/hengju.sqlite；浏览器草稿保存在当前站点的本地存储中。数据和 .env 均不进入 Git。恢复示例只需点击左侧场景，不会删除历史记录。

如果端口占用，请先关闭此前启动的本项目服务，或在生产启动时设置 PORT；开发代理默认固定到 4318。

## 体验路径

1. 选择“雾港炼金坊”：初始 12 金币，3 金币买 1 矿石，2 矿石炼 1 金属锭，金属锭卖 7 金币。
2. 约定矿石和金属锭恢复初始库存时，金币净增不能超过 0，点击“开始验证”。
3. 系统实际搜索得到四步反例：购买两次、熔炼、出售，金币达到 13，其他库存恢复为 0。
4. 查看“新手用 6 金币完成第一次熔炼”保留用例。点击“比较修复方案”：售价 7→6 满足保留要求；矿价 3→4 虽消除反例，但让新手卡在第二次购买，界面明确标记并禁用直接载入。
5. 载入候选后，旧结果会标为过期。点击“重新验证”形成新的实验快照。
6. 保存规则、导出报告，并到“实验记录”重新打开任意一次结果。
7. 用“旅人的行囊”检验误报边界：卖出初始物资使金币增加，未恢复其他库存，因此不属于本约束下的闭合套利。

## 可复现性的边界

当前实现固定成本、固定产出、非负整数资源和顺序动作。没有建模随机事件、冷却时间、同时行动、外部奖励与隐藏状态。

搜索最多 32 步、25,000 个状态，单次引擎预算最多 3 秒，并在独立工作线程中运行。触及预算返回“不确定”。“范围内未发现反例”不是全局安全证明，也不是游戏平衡评价。

短反例性质针对当前模型。修复候选来自反例中的参数调整，并重新执行原路径、同范围搜索和设计者声明的正常玩法用例。保留检查仅覆盖声明的路径及最低库存，不代表完整玩家体验或未建模条件。广度优先搜索是已有算法，本项目不宣称发明该算法。

## 可选模型配置

复制 .env.example 为 .env，填写 MODEL_BASE_URL、MODEL_API_KEY、MODEL_NAME，然后重启服务。不要把密钥写进前端或提交仓库。

在“从文字开始”中点击生成，才会把输入发送到所配置的服务。可能产生模型服务费用。缺失规则应返回澄清问题；候选须经 schema 校验，每个数值都必须附有输入中的原文片段，并由用户确认。

引用存在只说明引文可核对，不证明数值解释正确。温度为 0 也不保证不同时间生成完全相同的模型。

## 验证命令

```powershell
npm test
npm run build
npm run test:e2e
```

浏览器测试在 Windows 使用已安装的 Microsoft Edge；其他系统使用 Playwright Chromium，需要先执行 npx playwright install chromium。测试服务使用端口 4319 和独立目录 data/e2e，不写入使用者的项目数据库。

v0.2 本轮结果：16 项核心、API、模型协议及凭证测试通过；11 项浏览器测试通过。覆盖玩法破坏识别、完整可视化建模、草稿与连续撤销、凭证独立核验、AI 候选模拟预览和移动端；6 种界面状态的 axe 自动检查无违规。真实模型未连接，模拟服务测试不代表模型质量评测。前一轮运行依赖审计未报告已知漏洞；自动检查不等于完整安全审计或完整 WCAG 认证。

v0.1 归档版本的本机新项目目录复现耗时 26.189 秒，包含归档解压、安装、构建、11 项测试、启动与首次验证；Node/npm 已预装并使用现有 npm 缓存，不代表干净操作系统或首次下载耗时。具体计时与前提见 evidence/checks/reproduction.json。技术说明见 docs/06-architecture.md。

## 独立核验实验凭证

在界面导出“实验凭证”，运行：

```powershell
node scripts/verify-evidence.mjs "实验凭证.json"
```

核验规则指纹、独立重放反例、重新执行保留用例及同范围搜索。指纹证明内容一致性，不证明作者身份；受时间预算影响的未发现结论会明确区分未复现。凭证也可从“导入 / 编辑”载入规则和搜索范围，之后重新验证。
