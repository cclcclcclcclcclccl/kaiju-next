## 10 分钟复现

前提：Node.js 24.16 或更新的 Node 24、npm，以及首次下载依赖所需网络。

```sh
npm ci
npm run build
npm start
```

打开 http://127.0.0.1:4318 。本机默认只监听回环地址。Windows 日常使用可双击 `start-kaiju.cmd`；关闭启动窗口不会关闭后台服务，重启电脑后需要再次启动。

2026-10-21 在新目录安装、构建和空数据库启动实测 **32 秒**。使用本机预装 Node/npm 和依赖缓存，不包括操作系统、OCR 安装、外部数据请求或模型开通。证据：[复现报告](evidence/submission-v0251/reproduction.json)。这不是所有电脑必定在 32 秒内完成的保证。

```sh
npm test                 # 核心测试
npm run share           # 此 Windows 开发环境的临时分享入口
npm run backup:public   # 分享数据库在线备份
```

截图识别另需 Python 和 `npm run ocr:setup`；未安装时明确提示。可选视觉模型使用 `.env.example` 配置，当前体验版没有模型密钥，未执行专项训练。

## 重点功能

- **133 位英雄图鉴**：技能、图标、来源梯度、分段三率、出装铭文、皮肤分布和攻略入口；保留来源、日期和缺失说明。
- **逐手 BP 与摇摆位**：双方人工或人机操作、禁选、撤回、自动分路与手动锁定、系列赛历史。有限搜索会考虑对方回应，评分不是校准胜率。
- **个人与好友英雄池**：截图 OCR 核对、详细指标、保存冲突保护、好友双向确认和可撤销共享、1–5 人体系适配。
- **训练与复盘证据**：74 张英雄基础检查卡与 3 张通用卡，区分已研读文字与待研读视频；支持对局手记、关键帧和证据导出。
- **可靠保存与分享**：独立账号、断线恢复保留输入、保存不自动重试、SQLite 一致性备份、原始来源哈希。

推荐评审顺序：图鉴 → 分段梯度及来源 → 装备明细 → BP 摇摆位 → 英雄池保存 → 好友共享 → 对局手记/复盘证据 → 三条真实 AI 纠错链。

## 真实来源与能力边界

腾讯公开目录/分享榜、天元之弈公开统计、KPL 官方公开回放索引具有不同覆盖范围，不能混称“官方后台”。默认综合梯度来自天元原始来源，实验自研分数未校准为权威 T 档。未知分母不相加生成 BP 率，不编造缺失数据，不以装备胜率推断因果收益。

没有取得私有后台和官方账号同步，没有完成全部六分段全量统计、逐版本全英雄机制校准、职业级 BP 或复盘效果验证。视频索引不等于视频已观看或模型已训练。代码由 AI 辅助编写，不等于每项功能都在调用大模型。

英雄、皮肤、装备和相关图片归相应权利人所有。项目保留来源归属及图片映射/缓存；与腾讯、王者营地、天元之弈无隶属关系。第三方资料不作为本项目算法原创性主张。

## 架构和验证

React 19 + TypeScript + Vite 构建界面；Web Worker 执行有限搜索；Node 24 提供校验、缓存和可选模型适配；SQLite 保存按账号隔离的数据。公开来源读取采用查询缓存、结构检查、同查询旧数据回退和原始响应哈希。

当前本机 **117 项核心测试通过**，分享版本完成真实公网双账号注册、保存刷新、好友共享撤销及私有资料保全；另有 4 项本机浏览器回归和独立断线故障注入检查。[本轮验证](docs/36-sharing-reliability-v0251.md)。GitHub 自动验证另外检查 Linux 构建及容器重启持久化，以 Actions 实际结果为准。

## 固定地址与持续托管

完整功能需要后端和持久磁盘，不能直接用纯静态 GitHub Pages 替代。

- 容器：`Dockerfile`；必须设置真实 HTTPS `KAIJU_PUBLIC_ORIGIN` 并挂载 `/var/lib/kaiju`。默认不信任未知代理头。
- 当前预算决策：不新增付费，先用公开仓库、作品包、本机复现和临时体验入口完成参赛交付。[零新增付费方案](docs/38-zero-cost-submission-plan.md)。付费托管配置仅存为 deploy/render-paid-example.yaml 技术参考，本轮不启用。

不要上传本机 `data/`、个人数据库、`.env`、备份和原始录屏。迁移分享账号前，使用在线备份；固定站点必须经过重启保留账号/英雄池、跨网络访问与恢复测试才可称为完成部署。
