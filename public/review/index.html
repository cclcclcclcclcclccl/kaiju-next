五分钟体验路径

01 · 核查一位熟悉的英雄

进入英雄图鉴，搜索赵怀真，查看技能、来源梯度及分段表现。切换数据时关注来源与日期；缺失项不会补造。

02 · 保存你的英雄池

在我的英雄池添加几位常用英雄，按实际情况填写。刷新后检查记录仍在。数据保存在当前浏览器；更换设备或清理网站数据前，请从顶栏的备份入口导出。

03 · 让个人记录参与 BP

进入阵容备战，选择自己所在红蓝方和分路，启用“结合我的英雄池”。查看本分路可用英雄；点“分析这一手”比较候选和可能回应。选中后需要再次确认才会落子。也可选择人机对抗或双方人工操作。

摇摆英雄随后续选择调整分路，可以手动锁定。若英雄池耗尽，按面板提示改分路、补充记录或关闭池限制继续练习。

04 · 从备战到训练记录

体系练习支持1–5名成员，不要求五人齐备；录像复盘支持记录实际事件与关键帧。当前免费入口不提供自动视觉模型分析。

打不开时如何复现

公开入口不依赖作者电脑，但不同网络可能限制GitHub Pages。最终包内附离线体验站：预装Node.js 24后，进入离线站目录执行 node serve-review.mjs site，打开 http://127.0.0.1:4319/kaiju-next/；内置目录和统计无需联网下载。完整源码仍支持 npm ci → npm run build → npm start。
