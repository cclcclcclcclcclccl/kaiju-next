# v0.17：修复图鉴空数据、撤下未校准梯度、接入官方赛事素材

日期：2026-10-14。用户提供的廉颇详情和梯度榜截图是本轮验收入口。上一轮工程测试没有证明梯度合理，也没有覆盖从普通图鉴入口读取全榜的完整体验；此前“完成”的表述过宽。

## 原因与修复

**图鉴空白属于接线错误。** 普通图鉴入口读取的是已导入历史快照和每分路仅十条的官方分享榜，接通的天元全榜藏在另一个入口。没有手动导入、又不在十条分享榜里的英雄就显示“待接入”。现在图鉴列表、英雄详情和联网榜单都读取相同的天元公开接口；无需用户先导入统计。列表卡片显示梯度、胜率、出场率和禁用率；详情顶部展示梯度和三率，保留分段、统计日和梯度日。装备、皮肤、时长、克制与组合继续通过同一详情页的分类读取。

**开局强度v2的T档缺少专业校准。** 旧模型主要依赖总体胜率，千强模式还组合了顶端排位胜率与千强选禁，并按人工阈值分档。参数敏感性检查不能证明职业强度；“参数较稳”也不代表结论可信。本轮删除了联网榜单里这套默认展示和英雄详情里的对应评分，不通过手工抬高镜或压低伽罗来伪装修复。

**默认榜单改为天元来源梯度。** 直接读取 `/api/global/tier` 的分数，按实际公开 `/tier` 页的规则显示：T0≥70、T0.5≥60、T1≥45、T2≥30、T3≥15、T4≥0；分数降序，同分按来源战力赋值降序；分路筛选区分主分路、次分路。来源标注“算法测试中”，本项目不冒充原创算法。自研历史代码保留作复核，未继续作为默认权威榜。

**来源梯度是综合榜，没有gameMode参数。** 改变“大众/1350+/顶端/千强”只改变三率，不能将同一综合梯度谎称为四种独立分段梯度。榜单支持按胜率、出场率、禁用率、名称排序，切换排序真实生效；三率接口失败时来源梯度仍独立显示。

**两个来源日期并不相同。** 实测梯度接口可读取10月14日，匿名三率请求10月14日返回“您当前时段只能访问2026-10-13及之前的数据”。梯度日期按原站北京时间09:00的默认规则选择，统计日期仍选前一日；页面分别展示，不能混称为同日实时数据。指定日期失败不会自动换成其他日期。

## 官方KPL素材与复盘改进

已从 [KPL官方网站](https://kpl.qq.com/) 的公开页面确认匿名读取方式，使用以下官方接口读取赛程与素材索引，不使用游戏账号、Cookie或私有凭据：

- `https://kplshop-op.timi-esports.qq.com/kplow/getScheduleList`
- `https://kplshop-op.timi-esports.qq.com/kplow/getScheduleDetail`
- `https://kplshop-op.timi-esports.qq.com/kplow/getProgrammeList`（用于研究素材分类，未将集锦当作完整录像）

复盘页新增“KPL官方比赛素材库”，首次展开获取最近3场已结束系列赛的逐局回放。当前实测为重庆狼队对杭州LGD.NBW、北京JDG对济南RW侠、北京WB对深圳DYG，共12局。显示真实赛季、比赛标题、逐局英雄列表、官方回放链接和选手视角入口数量。读取结果缓存1小时；到期访问更新，失败保留原获取时间。测试材料索引、模型训练样本和推断结果分开。

没有下载或观看上述12局完整录像，没有训练模型，也没有验证每个视频均可播放。公开可观看不自动代表允许任意训练使用。本轮取得的是可追溯的候选素材入口，不能宣称复盘已达到KPL水平。

当前对话复盘包新增 `COACHING_PROTOCOL.md`、`DECISIONS.json` 和逐决策 `decision-*.json`。每个决策包只列出该时刻及之前的证据，并要求按时间顺序完成取证、战术比较、反证检查。分析维度包括兵线回城、视野路径、资源交换、技能装备窗口、阵容职责和沟通计划。明确区分观战全图与选手视野，不按最终胜败倒推当时决策。可选模型接口同时使用该协议，并拒绝遗漏或重复关键帧的结果。

这套提示与材料组织不是模型参数训练，也不能技术上保证一个能读全部目录的模型绝不会偷看未来文件；结果引用仍检查不能使用未来图像。网站当前没有配置自动视觉模型接口。本对话不会因下载更多录像而自动更新权重。

真正训练下一步需要：可用于训练的真实片段、比赛ID与版本、带时间点且经过复核的事实/决策标签、按整场比赛隔离的验证集、实际可调用的训练服务或可训练模型。已有“导出待审核评测样本”可保留人工纠错，但待审核样本不是已完成训练。职业效果应由独立案例和合格复核者评价，不能以模型自评代替。
