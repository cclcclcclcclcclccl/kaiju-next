# v0.14：英雄池保存与装备统计可发现性

本轮对应用户提出的“赵怀真不见了”“装备出场率、胜率没有了”以及成熟产品差距检查。日期：2026-10-14。

## 实际发现

- 开发前只读检查运行中数据库：访客英雄池仍有赵怀真（544，本命）和诸葛亮（190，正在练），完整性检查为 `ok`。没有发现赵怀真被删除的证据。
- 访客与独立账号隔离保存，但英雄池页面没有醒目标识保存身份；分路和搜索筛选为空时，提示也可能被误解为整个英雄池为空。没有读取用户正在使用的浏览器登录状态，因此不能认定其这次问题一定由切换账号引起。
- 旧前端每次提交完整英雄池，多页面编辑可能覆盖另一页新加的英雄。本轮确实修复该隐患，但不把它宣称为赵怀真此次不可见的已证实原因。
- 装备统计已经在英雄详情的“实际出装统计”中接入；装备库仍保留“暂无可靠公开统计”的过期提示。功能入口与文案不一致。

## 本轮行为

1. 英雄池首屏显示当前身份、保存位置、自选英雄数量、最近修改时间。旧数据没有修改时间时如实标注，不补造时间。
2. 独立账号可以预览并复制访客池中缺少的英雄；不覆盖已有标签、不删除访客池。该入口仅复制自选英雄和标签，不复制详细战绩。
3. 支持重新读取和导出自选英雄备份，并查看最近 20 次保存前后记录。截图与详细战绩仍在玩家档案。
4. 前端按变动英雄提交，服务端事务中比较预期旧值。同一英雄冲突返回 409，前端提示并重新读取；不同英雄的修改可合并。旧 `/api/pool` 全量接口为兼容保留，不能宣称所有外部客户端均已防覆盖。
5. 装备与版本增加“装备出场率 / 胜率”入口，装备库内也可直接进入。支持 133 位目录英雄选择、查询日期、按出场率或胜率排序、名称筛选、图鉴跳转和来源导出。
6. 切换英雄或日期时不沿用上一查询的表格；失败明确显示。旧缓存只能对应同一查询，保留原获取时间。

## 真实数据与口径

2026-10-14 的实际请求成功取得查询日 2026-10-13 的装备数据。赵怀真、海月各返回 10 件装备；赵怀真冰霜冲击出场率 79.82%、胜率 50.52%；海月日暮之流出场率 92.37%、胜率 52.46%。这些是来源响应的统计值，不能解释为装备带来的胜率增益。

来源为 `https://tianyuanzhiyi.com/api/hero/equip` 公开接口，不是腾讯官方后台。数据按英雄查询，不提供分段选择、样本场次和完整分母定义；不聚合成虚构的全英雄装备总榜。来源统计截止与用户查询日分别展示，不假定两者同义。公开接口原始响应保留在本机来源归档中。

## 与成熟同类产品相比的优先级

这是对当前实现的审查，并非本轮重新逐屏验收王者营地 App / 微信小程序后的竞品评分。

| 维度 | 当前不足 | 下一步验收条件 |
| --- | --- | --- |
| 保存和可恢复性 | 本机实例存储，无跨设备云备份；详细档案仍是整份保存 | 详细档案增加版本冲突保护；统一备份导入与恢复验证 |
| 数据可用性 | 四种来源分段不是用户期望的六分段；第三方会空响应或超时，样本与分母不完整 | 分段覆盖矩阵、持续成功率和新鲜度记录；取得缺失来源后才增加榜单 |
| 梯度可信度 | 已有独立强度公式、敏感性分析，但尚无跨版本预测效果评测 | 固定算法版本，以留出日期数据和独立专家标注比较稳定性及误差 |
| BP 专业水平 | 有多手博弈搜索与个人池约束；完成自对弈不证明职业级 | 按版本留出真实 BP 样本，建立可复现基线及教练盲评，测建议质量与耗时 |
| 复盘能力 | 本地关键帧交给当前 Codex 对话分析并导回；不是网站自动调用的专项训练模型 | 真实玩家录像决策点标注、证据引用准确率、错误建议率与训练前后对照 |
| 产品使用成本 | 页面功能偏多；部分外链图片失效；英雄资源包仍偏大 | 常用任务可发现性测试、移动端弱网测试、图像降级与资源按需加载 |
| 个人账号接入 | 截图识别需核对；没有游戏账号自动同步 | 得到合法可用的授权接口或导出来源后接入；未得到前不伪造同步状态 |

## 验证方式

- 核心测试覆盖数据库重开、不同英雄合并、同英雄冲突原子性、账号历史隔离、幂等访客复制、非法输入拒绝。
- 浏览器使用独立测试库 `data/player-e2e`，验证账号恢复、刷新、搜索空态、双页面并发保存、实际来源 fixture 的装备值与排序、查询失败不串数据、移动端可访问性。
- 浏览器测试中的账号和修改是测试数据，不是用户记录；装备 fixture 来自归档响应，不生成胜率。
- 升级前备份实际数据库；升级后对旧表逐项比较，只输出摘要及校验值，不公开账号凭据。
- 测试结果与本机运行验证保存于 `evidence/reliability-v014`。旧验收材料在测试后按备份恢复，避免本次截图覆盖历史留痕。
