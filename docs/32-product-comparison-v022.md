# 同类产品对比与 v0.22 改进

核验日期：2026-10-20。目标：减少查找和解释成本，让真实数据支持个人备战。调查仅走公开网页，不登录、不购买、不绕过验证。

## 自评

开局已经具备可操作的数据查询、个人英雄池、摇摆位推断、系列赛 BP、多人体系与证据复盘流程。它的差异化在个人备战流程的组合，而不是独占统计数据或经过职业训练的模型。现在适合作为可演示、可继续验证的实用作品；尚不应宣称比成熟数据站更准确、已经具有 KPL 级分析能力，或覆盖它们全部私有功能。

主要不足是入口分散、数据口径说明位置不统一、难以并排比较候选英雄，以及新增功能没有完全接入原有备份流程。本轮直接修复这些问题。

## 已落实

1. **英雄横向对比**：首页直接进入，或数据与工具中选择。2–4 位英雄共用日期、分段、同一个来源包，展示三率、KDA、前中后期、输出承伤经济与战力；标注是否在自己的英雄池，可以导出对比与原始出处。缺失英雄保持未知，查询失败不会留着上一分段的数据。样本未公开，不给出伪显著性或胜负预测。
2. **功能搜索**：顶部支持英雄名字/拼音及“皮肤”“BP”“复盘”“战力”等任务，直接跳到对应工具。Ctrl/Cmd+K 聚焦、Enter 执行、方向键进入结果、Escape 关闭。手机也可使用。
3. **首页捷径**：梯度、对比、英雄池与图鉴、BP、手记形成直接入口，减少在多个标签页中寻找。
4. **统一口径栏**：公开数据区域上方直接显示统计日/独立窗口、适用分段、缓存状态与北京时间获取时间。详细 URL 和 SHA-256 继续保留。
5. **纠正 BP 率**：全英雄扩展表曾将出场率与禁用率直接相加；来源没有提供可核实的共同分母，已删除该合成值和列，并解释原因。来源分别公布的出场率、禁用率原样保留。
6. **完整备份包含服务器系列赛**：新备份带入服务器 BP；预览展示局数；恢复增加版本防覆盖。旧备份未提供该字段时保留现有系列赛并明确显示。浏览器尚未上传的演练仍需单独导出。
7. **手机隐藏导航不可误聚焦**：收起的侧栏使用 inert，避免键盘或辅助技术进入屏幕外控件。

## 验证与保留项

- `core.txt`：105 项核心测试通过，新增搜索路由、系列赛备份恢复、旧备份兼容与版本冲突用例。
- `browser-first.txt`：14 个浏览器场景通过，包括来源回归、备份、失效登录、编辑保护及新功能。
- `browser-final.txt`：手机导航补充后 4 项专项复验通过。正式运行页面核验另存 `live/verification.json`，不以夹具测试替代实网检查。
- `live/verification.json`：正式站点 v0.22.0 实网核验通过，同批次英雄对比、功能搜索、手机导航开合及备份新字段正常；页面脚本异常为 0，workspace/pro 与改动前完全一致，英雄池仍为赵怀真（544）及诸葛亮（190）。数据库升级前备份保存在 `data/product-v022-before/kaiju.sqlite`。
- 测试使用 4319 独立数据目录/内存数据库；生产数据只读核对。真实统计夹具与合成存档测试明确分开。
- 第三方数据持续性、官方完整分段与账号授权、纯头像识别、职业级 BP/视频复盘、真实多人长期可用性仍未解决。大体积前端资源的构建提示仍存在。

## 下一阶段应以什么证明质量

优先做真实玩家任务测试：能否快速找到某英雄、正确理解分段、完成一次 BP 并恢复、从复盘中带走可执行动作。再建立版本固定、可复现的 BP/复盘评测集，由有经验玩家或教练独立评价。没有这些证据，功能数量和模型调用次数都不能证明职业水平或获奖概率。
