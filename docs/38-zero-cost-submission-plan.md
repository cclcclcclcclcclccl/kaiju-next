# 零新增付费的参赛交付方案

当前决定：不购买云服务器、不购买域名、不订阅模型 API。先完成可检查、可下载、可复现的参赛材料，新增付费预算为 0 元。

## 当前采用

| 需要 | 采用方式 | 当前状态 |
|---|---|---|
| 评审代码与真实历史 | GitHub 公开仓库 | 已建立并上传，保留原始提交与修复历史 |
| 完整材料 | GitHub Release + 本地 ZIP、PDF、MP4 | 本轮整理交付，以最终校验文件为准 |
| 独立复现 | 评委电脑 Node 24 + npm | 新目录安装构建启动已验证；依赖安装需要网络 |
| 临时在线体验 | 当前电脑 + 已有免费临时通道 | 需要电脑开机联网，可能换网址，不保证校园网均可用 |
| 基础 BP 与推荐 | 已有本地确定性算法 | 不需要模型 API 账单 |
| 截图 OCR | 本地识别，用户核对 | 无模型 API 调用费用，另需安装 Python/OCR |
| 专业录像分析 | 现有证据整理/导出流程 | 没有付费视觉模型，不宣称已自动实现专业分析 |

这里的 0 元指本轮不新增购买服务，不包含电脑、电力和既有网络成本。

## 为什么先不买服务器

用户提供的赛事正文要求：GitHub/Gitee 仓库及历史、三条 Prompt 链、复现指南、5-8 分钟 1080p MP4 和不超过30页 PDF。正文未单列永久公网网址。满足材料要求与保持一个全年在线的网站是两个任务，不能为了不明确的条件先付费。

最终个人中心若出现新的固定网址要求，再核对对应条件。先查看能否使用学校/实验室提供且明确获准的服务器，或学生权益资源；这些当前都未申请、未验证，不能把可能的优惠当作已经获得。

## 免费托管的验收条件

完整功能含账号与英雄池数据库。免费服务如果休眠、磁盘不持久或必须绑定付费项目，会影响使用。只有同时通过公开 HTTPS、目标网络访问、重启保留数据、备份恢复和额度确认，才可作为固定演示入口。GitHub Pages 的纯静态页面不能直接替代本项目后端。

不将 GitHub Actions 运行器冒充长期服务器，不把会重置数据库的免费演示称为正式服务，不预填付费套餐让用户误确认。

## 未来确需小额费用时

先明确最低需求：一个能运行 Node 的进程、持久磁盘、HTTPS 和备份；不为开发期购买 GPU、大模型训练、商业域名、数据库集群等额外服务。届时比较可实际使用的学生权益与最低可用方案，拿到当时的报价、计费周期和续费条件后再由用户确认。

`deploy/render-paid-example.yaml` 仅作为已保存的技术参考，不在根目录启用自动部署入口，本轮不使用。没有创建或购买任何 Render 云服务。
