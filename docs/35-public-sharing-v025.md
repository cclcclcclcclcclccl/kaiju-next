# 公网分享与恢复 · v0.25

## 同学如何打开

将 `data/public-site/PUBLIC_URL.txt` 中的 HTTPS 网址发给同学。不要分享 `127.0.0.1:4318`：它只指向访问者自己的电脑。

2026-10-20 当前体验地址：<https://downtown-relates-indexes-trustees.trycloudflare.com>。这不是固定域名，隧道重新建立后可能变化，以文件和启动窗口显示的已验证地址为准。

同学打开后可浏览公开资料、练习 BP；保存个人英雄池、档案和复盘前，请到“注册 / 登录与好友”建立开局账号。这不是王者游戏账号。换设备后，在同一分享网址登录同一账号，可读取服务端保存的资料。换域名后需要重新登录，但只要保留分享数据库，账号及资料仍在。

## 双击启动与恢复

1. 本机安装 Node.js 24.16 或更新的 Node 24，项目已完成依赖安装和生产构建。
2. 双击根目录 `share-kaiju.cmd`。它复用健康通道，必要时启动独立分享服务与 Cloudflare 临时通道，并验证真实 HTTPS `/api/status` 后才输出成功。
3. 分享启动窗口输出的网址，或打开 `data/public-site/PUBLIC_URL.txt`。若启动失败，不要将文件中的旧地址视为仍可用，应查看窗口错误。
4. 启动窗口可关闭；**电脑必须开机、联网且不休眠**。电脑重启后再次双击；新地址需要重新发给同学。

命令行等价入口：`node scripts/player/share.mjs`。在保留隧道网址的情况下重启分享后端：`node scripts/player/share.mjs --restart-server`。脚本核对服务、父进程及隧道身份后才操作，不停止原有 4318 私人工作台或其他项目的隧道。

公开服务监听 `127.0.0.1:4320`，只由隧道转发。独立数据库位于 `data/public-site/kaiju.sqlite`；备份时应停止分享服务后备份整个 `data/public-site`，包括 SQLite 旁路文件，不要用原有 `data/kaiju.sqlite` 替换它。

日志：`data/public-site/cloudflare.log`、`data/public-site/service.log`。首次部署到另一台电脑需要准备 Cloudflare 官方 Windows x64 程序 `tools/public-access/cloudflared.exe`；版本 2026.10.2，SHA-256 `12c7c887f8aaab779aef1dfa9b60673530a5adb88ecc55dd6df8f56e0b70f199`。源码中的下载脚本依赖同目录官方 release.json 记录，分享启动器也核验摘要。

## 当前边界与正式部署

本次解决“把 localhost 发给同学打不开”，不等于已经取得稳定生产托管。验收是本机经真实公网往返，没有替代同学所在校园网、移动网络的实测；临时 Cloudflare 域名在不同网络下可能连通性不同，无服务可用性保证。

正式参赛长期演示建议部署到有持久磁盘的持续在线服务器，配置固定域名/HTTPS、数据库备份、进程守护和访问监控，再从校园网及手机流量验收。尚未购买或配置云主机、固定域名，也没有修改电脑电源策略。

为了隔离原有个人资料，本次只复制公开数据缓存，没有复制私人账号、英雄池和复盘。分享服务不载入本机模型密钥；当前没有可调用的视觉大模型，不能宣称公网自动专业复盘。访客可浏览和使用客户端 BP；需要保存的功能要求登录。本机 Codex 文件交接接口不向公网提供。

本轮优先处理联网问题，原计划的梯度算法校准、BP 比赛样本评估和复盘质量评测没有因此完成。
