# v0.13 自研强度梯度与当前对话复盘

核验日：2026-10-14（北京时间）。本轮回应两个问题：默认榜单必须给出自己的强度判断；复盘希望使用当前 Codex 对话，而不是只有一个未连接的模型按钮。

## 强度算法与入口

分段梯度默认进入“开局强度与全榜”，默认选择“开局强度梯度”和“开局强度”排序。天元的来源梯度只作为另外一个参考页签保留。数据来自天元公开接口，自研计算不读取其梯度评分、T标签或排名，也没有以其标签作为训练目标。

算法版本为 `开局强度 v2.0`，实现位于 `src/player/pro/strength.ts`。这是可解释的启发式统计指数，不是训练好的预测模型，不代表相对于天元更准确的结论。

1. 用完整定位英雄集合计算，先计算再搜索。总体三率不能称为某个分路的独立胜率。李信光暗形态保留在原始数据页，基础英雄强度集合不重复计入形态。
2. 胜率按中位数与 MAD 尺度标准化：`zW = clip((win - median(win)) / max(1, 1.4826 × MAD(win)), -2.5, 2.5)`。比例输入单位为百分点。
3. 出场和禁用先取 `log(1+x)`，再稳健标准化；尺度下限分别0.35、0.5，标准化值限制在±1.5。避免单项极端值无限推高评分。
4. 胜率项乘 `sqrt(p / (p+k))`；`k = max(1, median(p)/2)`。p来自胜率参考的同一数据组。此项保守削弱极低使用英雄的胜率影响，不把出场率冒充样本量，也不能证明消除了绝活玩家偏差。
5. 大众、1350+、顶端：`S = clip(50 + 18 × (0.70 × zW × 衰减 + 0.18 × zP + 0.12 × zB), 0, 100)`。千强用同查询日顶端排位胜率作代理，结合千强选禁；权重分别0.60、0.24、0.16。页面明确标注“千强代理强度”。
6. T0≥70、T0.5≥62、T1≥54、T2≥46、T3≥38，其余T4，不强行分配人数。胜率或代理缺失、可比集合不足五位有胜率英雄时保持“待评估”。
7. 胜率权重上下浮动0.1、选用占剩余权重比例0.5/0.6/0.7、k倍率0.5/1/2，合计27组参数，返回分数范围、排名范围与可能梯度。这是参数敏感性，不是统计置信区间。相同分数共用名次，ID只用于稳定显示顺序。

选用/禁用/胜率排序仍保留；按单项指标排序时重新排整个筛选集合，自研标签仍展示。点击英雄后在技能长文之前显示统计与评分解释。

## 真实数据评估

`npm run strength:evaluate -- 2026-10-13` 校验输入原始响应SHA-256，生成 `evidence/strength-v2/evaluation.json`，包括四分段×（全部+五定位）=24张计算表。

四分段各133位基础英雄。全英雄榜参数检查跨档人数依次为大众82、1350+80、顶端84、千强78，页面必须明示敏感性。千强自研标签与发布者有92位不同；差异不证明更准确。没有用“更像参考榜”调整权重。

仍缺总体样本场次、完整窗口、独立对局结果和版本切分。国服战力受玩家和系数影响，未强行加分。自研分未直接用于BP，需额外验证口径与预测收益。

10月14日晚的实际检查中，查询10月13日顶端排位的接口返回HTTP 200但内容为空数组，结构校验拒绝覆盖。运行页面使用此前采集的同日真实缓存，并显示更新失败提示。不是刚刚刷新成功的统计；证据见 source-refresh-check.json 和 live-check.json。

## 使用当前 Codex 对话复盘

1. 网页打开录像，播放到实际画面后截取决策点。笔记可先留空，准备包时明确标为未填写，不捏造观察。
2. 点击“准备当前对话复盘包”。仅写本机 `data/review-handoff/<账号哈希>/<UUID>/`，包含原始JPEG、input.json、FORMAT.md，不自动发送聊天消息或新增外部模型调用。
3. 把生成的指令发到当前 Codex 对话，由助手实际查看图像、分析证据和未知，再按格式写 result.json。
4. 点击“读取 Codex 复盘结果”。检查输入和原图哈希、包ID、时间点、图像引用及覆盖。不能引用不存在或晚于决策的画面作为当时依据；账号之间隔离。
5. 页面显示有依据的建议或证据不足、替代选择、练习和未知。人工校正可导出待审核样本，不会训练模型。

页面切换会清除未保存的临时编辑状态；复盘包文件保留在本机，可通过已复制的目录找回。当前流程需要聊天中发起分析，不等于网站独立自动调用助手。原有可选视觉接口仍保留，但本机未配置。视觉适配器最多分析前六帧，本地对话包保留全部所选帧（最多30）。

## 训练与能力边界

没有完成王者荣耀专项训练，没有真实录像质量评测，不宣称职业级复盘。重复提示或多阶段推理不等于训练。需积累原图、人工校正和建议样本，按对局划分训练、开发、独立测试集，避免同场对局泄漏。

原拟加入向可配置服务发送截图和笔记的三阶段模型流程，自动审批因目的服务与发送范围未具体授权拒绝该代码，未写入或启用。用户随后选择当前 Codex 对话，已实现不新增网络外发的本地交接。官方 Codex 接入文档在本机返回403，未据此声明订阅或SDK的接入能力。

核心测试覆盖去重、来源标签独立、顺序不变性、并列名次、缺失隔离、账号与原图验证、未来证据拒绝。浏览器合成视频只验证交接协议，测试生成的结论不作为AI效果证据。最终验证见 `evidence/strength-v2/validation.json`。
