# BP禁用保护与英雄池可用性

2026-11-11，v0.27.1。此次修订解决操作与搜索中的具体缺陷，不新增付费服务。

## 修复前后

| 原问题 | 当前行为 |
|---|---|
| AI可能建议禁掉己方登记成员唯一可用的英雄 | 在截取候选集前检查本方剩余英雄池的可行分工，排除使其无解的禁用建议；红蓝两方均适用 |
| 对方登记英雄池耗尽会中止己方计算 | 只要求当前行动方满足约束，对方问题以提示呈现 |
| 对方阵容已满时，没有可选英雄就可能没有禁用候选 | 禁用候选覆盖尚未禁选的目录英雄，仍遵循己方英雄池保护 |
| 用户不知道为什么自己的英雄不能选 | 显示“我的分路可用英雄”，区分已禁用、对方已选、队友已选和系列赛前局已用，配头像 |
| 同一摇摆英雄的不同分路占用多个推荐卡片 | 首屏最多显示三位不同英雄；搜索仍保留分路方案 |

## 如何体验

在英雄池登记常用英雄，然后进入阵容备战，选择自己的红蓝方与分路，并启用个人英雄池。可用英雄面板显示当前分路支持情况；点头像只是选中，不会替用户确认。点击“分析这一手”，比较候选理由、后续回应与方案值差距，再自行确认。

人类仍可手动禁用自己的英雄。如果本分路无英雄可用，面板会说明原因，并提示调整分路、补充英雄池或关闭英雄池限制；对方AI的合法回合不会因此一起停止。队友已选摇摆英雄仍可通过分路调整换位。

## 验证与边界

新增6项回归测试，核心测试共133项通过。新增用例在修复前分别复现禁用保护、对方耗尽、完整对方阵容及可用英雄统计问题；日志保存于 `evidence/bp-refinement-20261111/`。

浏览器用独立构造档案验证真实Worker、手动确认、刷新持久化、红方分路偏好、候选去重、唯一英雄禁用保护、手动禁用后的提示和对方AI继续；检查1440、768、390像素宽度无横向溢出。这些是工程验收，不是真实玩家试用。

方案值是启发式搜索比较分，不能解释为对局胜率。英雄池保护只基于已登记资料和当前禁选条件，不保证未来对手继续禁人后仍有解。可用英雄列表只是按记录和当前状态筛选，不是独立的战术排名。未获得的队友资料保持未知。
