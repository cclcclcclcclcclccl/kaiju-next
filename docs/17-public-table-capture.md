## 玩家现在怎么检查

打开 `http://127.0.0.1:4318/`，进入“分段梯度”，统计分段选“巅峰千强”，数据批次选“天元之弈公开参考 · 16位英雄（已核对）”，看板依据选“来源原始统计”。16 位有数据的英雄会与未收录英雄分开展示；完整目录仍有 133 位，未收录不表示弱势。点击镜，可在对应图鉴查看胜率 52.4%、出场率 19.9%、禁用率 46.5%，以及来源和数据日。

已有个人快照时会保留原选择，另有“查看天元之弈公开参考”按钮；内置批次不写入玩家数据库，不覆盖此前海月详情中的两位小数。

营地原有匿名公开分享接口继续提供大众、巅峰1350+、顶端排位的数据，每分路最多十条。该接口属于官方公开分享数据，不是登录账号同步或私有后台。

## 批量导入操作

“导入统计快照 → 榜单截图识别”支持一次最多 12 张 PNG/JPG/WebP、每张 8 MB。每张保留完整表头、英雄名、分路和三率。当前识别器在天元之弈上述实际布局验证；营地可选作来源，但不同布局不保证直接识别成功，可用已有表格粘贴或 JSON 入口。

1. 选择同一来源、同一天、同一分段的截图，逐张执行本地 OCR。
2. 相同图片按 SHA256 去重，同英雄同分路相同三率合并，保留文件出处。
3. 同英雄三率冲突，必须明确选择或排除；不同数据日不能合成一批。
4. 核对后把记录填入下方表格，补齐分段、日期和来源口径；缺失场次留空。
5. 预览并核对后才保存。修改图片或冲突选项会使旧预览失效，修改来源会清空截图识别状态。

识别核对记录可以独立导出，保留完整哈希及被排除记录；统计快照保留简短哈希索引。识别阶段不写数据库、不保存原始图片、不发往模型服务。取消只停止后续识别，已发出的单张请求可能继续到结束。

此入口首先解决数据维护和有来源的自助导入，不要求普通玩家每次查看榜单都自己截图。自动全榜采集仍是需要补齐的服务能力。

## 本轮同时修正

- 原始三率可以直接展示，不再因为没有样本量而完全看不到可用数据；正式梯度仍有口径和样本检查。
- 官方热度、原始来源统计和自研梯度分别选择，来源日期始终可见。
- 总表胜率排序与详细表格跟随选择的数据来源，避免看板和表格混用数值。
- 内置参考可被所有本地账号选择，独立于用户保存的统计；英雄详情沿用所选批次。
- 批次选择器增加稳定的可访问名称；移动端表格在卡片内横向滚动。

天元之弈全量六分段持续更新、全部皮肤使用率、比赛时长分组胜率和游戏账号同步均未完成；本轮没有改变这一事实。只有截图首屏、部分官方公开接口与已核对局部批次，不足以宣称数据优于天元之弈，也不足以证明 BP 达到职业水平。

验证结果见 `evidence/public-capture/validation.json`。真实来源采集、测试模拟响应和用户数据相互独立；测试使用 4319 端口及 `data/player-e2e`。
