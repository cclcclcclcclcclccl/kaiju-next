## 原文中需要官方确认的问题

1. 用户称“AI 创新应用挑战赛”，正文称“全国高校 Vibe Coding 开发挑战赛”。需要确认这是同一报名项目及当前有效赛题。
2. 省赛评审意见“预计于 2027 年 1 月底发布”，晚于所列国赛 2026-12-27 截止。不能自行修正年份，也不能假设可等待反馈后再交国赛。
3. 国赛二等奖/三等奖比例一处为 20%/35%，末尾为 25%/30%；一等奖均为不超过 5%。
4. 省赛一处按本省人数计算，末尾又按六大赛区、科目和组别排名，实际评奖范围待确认。
5. 推荐方向第 6–10 项有名称、示例错位，部分文字截断。可据“解决真实问题”等稳定要求选题，不能凭残缺示例推导限制。
6. “10 分钟极速复现”是否包含首次网络下载、账号注册和模型密钥申请，原文未定义。项目将公开实测前提，并同时提供无需密钥的标注演示数据模式与独立的真实 API 模式。

以上为待核实项，不阻碍原创选题、证据归档和本地开发。
