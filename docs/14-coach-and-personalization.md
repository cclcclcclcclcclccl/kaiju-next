# 五项玩家需求升级 · v0.8

日期：2026-10-12。产品：开局 NEXT。参赛者：蔡晨霖，西安交通大学人工智能 2501 班。

本轮围绕“我与队友真正适合拿什么，对方会怎样回应”升级现有项目。下列“已实现”指可以操作并通过工程测试，不代表经过职业教练验证，也不代表已经达到最终参赛验收。

## 从哪里开始检查

打开 `http://127.0.0.1:4318/`，刷新页面，侧栏应显示 v0.8。

1. **玩家档案**：填写偏好位置、打法、操作接受度与训练目标；添加自己常用的英雄，填真实数据后保存。胜场和胜率任选一种，其他未知指标可以留空。
2. **我的英雄池**：查看准备度及场次、评分、胜率、当前/历史战力。上方展示三位适配英雄，可展开更多；点击“编辑某英雄详细数据”直接进入对应记录。
3. **阵容备战 → 教练博弈 BP**：从未选满的阵容开始，展开“选手分工与对手线索”，为我方位置指定本人或共享好友。选择深度后计算，阅读“我方选 → 对方选 → 我方应对”的线路。只应用第一步，看到实际选人后重新计算。没有登记可用英雄时，先补档案，或明确取消英雄池限制做练习推演。
4. **分段梯度 → 全部英雄**：默认列出官方目录的全部 133 位。搜索任一英雄并打开图鉴，查看技能、三率/热度来源、搭配克制、官方攻略、出装铭文、个人训练卡。
5. **好友与组队 / 体系练习**：双方接受好友关系，对方开启档案共享；在体系页勾选成员，查看优先推荐、由真实英雄池生成的组合、谁负责哪个位置以及练习缺口。

## 算法与可解释性

### 个人准备度

优先选择近期、其次本赛季、最后累计胜负样本。胜率使用 20 场、50% 的中立先验；场次经验按对数增长。可用特征的初始权重：经验 0.30、平滑胜率 0.35、评分 0.20、战力 0.10、历史保持度 0.025、表现分 0.015、游戏熟练度 0.01。缺失项不补值，剩余权重重新归一化。

可信权重随样本量增长，按 90 天指数衰减；赛季样本乘 0.75，累计样本乘 0.45。有实战记录时不足部分向中立 50 收缩，无实战样本时保留自报标签/未知基线。只填高战力不能得到高熟练度。权重与评分刻度是项目启发式，未经当前版本或玩家群体拟合。

巅峰/挑战加成均明确填写百分数。两项已知时，战力参考以 `战力 ÷ (1 + 两项加成合计 / 100)` 作低权重比较近似；不是官方战力公式。巅峰能量不当作操作实力，历史最高不能替代当前战力。档案中的计算依据可展开查看。

### 双方教练搜索

局面评价是“我方 - 对方”。包含已分工选手的准备度、满足既有口径/样本/时效要求的版本统计、队伍前排/控制/物法覆盖、官方伙伴与克制关系、反突进保护、已知体系核心。未指定队友及未知对手使用中立准备度，不套用本人的英雄池。已知对手常用英雄只影响候选排序和倾向权重，不自动增加其实力。

蓝方选人次序按 1–2–2–2–2–1 展开为单个英雄动作，红方对换；可手动改下一手，剩余容量仍限制双方各五人。稳健模型使用有限候选中的最强回应，倾向模型按启发式偏好加权。倾向模型展示的线路为最不利分支，方案分是加权值，不是该线路单独的收益。

每层全算完才替换结果；预算耗尽保留上一完整层。界面显示实际搜索节点、局面评估次数、耗时、剪枝和缓存命中。候选被截断，不能把方案值描述为胜率或全局最优。搜索运行在独立线程，阵容/参数/成员/记录变动立即取消旧任务并清除旧结果。

**可复核对照**：测试构造三个中路英雄，A 有控制覆盖、B 更稳妥、C 能针对 A。独立手算两手收益得到 A 的最坏值 -4，B 的最坏值 -1；一手贪心选择 A，两手搜索选择 B。测试同时核对每个候选分值，证明实现确实考虑对方回应。它是合成算法正确性测试，不是游戏胜率实验。

### 体系适配

模板核心和自适配组合均经过不同成员分配，不允许一人占两路，也不虚构英雄池外角色。自适配生成保护输出、控制跟进、消耗防反三类候选，使用宽度 32 的有限搜索。排序优先完整覆盖，再按 `50 × 核心覆盖率 + 0.35 × 平均准备度 + 0.15 × 最低准备度` 评分；开启打法档案时准备度含 15% 风格适配。

## 官方图鉴资料核验

除原有英雄目录和逐英雄官方页面，新增：

- 装备：`https://pvp.qq.com/web201605/js/item.json`
- 铭文：`https://pvp.qq.com/web201605/js/ming.json`

133 位英雄均解析出装备和铭文资料。旧铭文字典存在历史颜色编码，现按英雄页面 `fuwenid_red/green/blue` 的实际槽位标色。例如鹰眼为绿色、隐匿为蓝色，浏览器测试已验证。部分旧攻略中的装备 ID 不在当前字典中，保留未解析 ID 并在界面说明方案不完整，不静默假装完整六神装。官方没有给出铭文数量，项目不补成各十个。

获取时间不是版本时间；官网旧攻略与当前游戏可能存在差异。没有在本轮重新访问微信小程序或王者营地 App，不能声称本轮已经对照它们的新界面逐项复刻。以前的实际参考记录见 v0.6 文档。

## 验证、证据和仍需完成的工作

本轮核心测试新增详细档案校验、准备度敏感性、习惯改变推荐、红蓝双方选序、两手手工穷举对照、合法性与计算预算、对手偏好、真实成员体系、官方资料引用。浏览器新增档案保存/刷新/取消入池、133 位总表到图鉴、铭文颜色、真实 Worker 计算/应用/失效、两真实测试账号的共享及撤销。

最终运行计数、截图与实际服务状态见 `evidence/coach-upgrade/validation.json` 和 `live-check.json`。文件名含 `test` 的截图使用隔离测试数据库的合成个人资料，不代表蔡晨霖的游戏战绩。完整 133 位资料静态打包约 1.23 MB，生产构建仍提示资料块较大；尚未做逐英雄详情按需加载。

要继续提升到参赛成品，需要：真实玩家填入本人数据并完成试用；真实 BP 案例及教练复核；公开全榜数据授权/稳定来源；跨设备好友部署；真实复盘模型与对局效果评估。这些不能用工程测试通过替代。账号同步需要可验证的授权接口或用户本人导出的数据，当前不要求用户交出游戏密码。
