# 质量与获奖竞争力优先的选题和实施计划

日期：2026-10-11。**方向尚未锁定。**

用户授权 AI 比较方向，要求越快越好、控制费用但质量优先；随后明确“方向目前先不确定，以拿奖为最高优先，一定要能够做出有创新有能力的内容，质量一定要非常高，主要据此确定方向”。校园经历、专业或游戏兴趣只是可利用资源，不是选题的决定依据。

## 五个选题门槛

1. 真实用户：说明谁在什么任务中花费时间或犯错，并有办法接触真实试用者。
2. 同类差异：相对现有产品指出一个窄而有意义的改进，能够通过案例验证。
3. 技术核心：除调用模型 API 外，有可以单独测试的算法、约束或交互方法。
4. 效果验证：能设计对照、固定评价集和失败标准，不靠模型自评证明正确。
5. 单人可交付：在截止日前实现完整闭环、稳定演示和可复现安装，不依赖不可获得的数据或大型训练。

先按门槛淘汰，再按官方 25/25/20/15/15 权重比较证据强弱。证据不足写“待验证”，不虚构获奖分数。目标为所给规则中的 A 组全国总决赛一等奖，不作获奖承诺。

## 当前三个候选

| 候选 | 用户问题与技术核心 | 关键风险 |
| --- | --- | --- |
| 衡局：游戏机制反例测试与修复验证 | 小型游戏/桌游设计者发现规则组合漏洞；意图约束、有界搜索、短反例回放、修改后回归对比 | 真实设计任务尚缺；模拟工具成熟；不能声称通用于大型商业游戏 |
| 契证：从业务需求到验收反例 | AI 写出的应用违反人数限制、重复提交、状态流转等业务规则；独立契约、失败操作序列和可复现证据 | 竞争拥挤；任意应用接入成本高；需求歧义影响判定 |
| 变更推演台：可解释的资源调度 | 临时换场地、改时间后解释冲突，提供改动较少的方案；来源约束、无解原因、方案取舍与历史 | 调度工具成熟；需证明具体使用场景的新增价值 |

“班策”保留为第三方向的早期候选，不是已批准或确定的产品。

公开资料初查见 04-direction-research.md。先验证“反例搜索—回放—修改后回归”的小型技术核心，它能快速暴露可行性边界；此实验不代表锁定游戏方向。

## 如何确定方向

每个候选需形成：一页问题定义、现有替代方式、一个竞争差异、一项最难技术点的小实验、一个 60 秒演示和一个可证伪指标。

优先检查实际难点，不先铺设登录后台或精细品牌视觉。技术通过后核查真实任务获取路径；没有真实用户证据，合成案例只能证明部分技术可行。

最终推荐写明证据、未知项、备选和淘汰理由。AI 可以依据用户授权完成比较和推荐；若用户反馈或实验推翻假设，应调整，不为维护已写代码而坚持原方向。

## 阶段与验收

| 阶段 | 目标节奏 | 产出与验收 |
| --- | --- | --- |
| 0 规则和候选 | 当前轮 | 原文归档、评分映射、Git、同类核查、首项技术实验；区分事实与假设 |
| 1 选题收敛 | 目标随后 1–2 个工作日 | 难点评估、场景路径、差异比较；形成一个主方向和明确验收标准 |
| 2 完整业务链 | 选题后约 3–5 天 | 输入→核心计算/AI→可解释结果→用户操作→保存/导出；新输入可跑通 |
| 3 创新和价值验证 | 随后约 5–7 天 | 基线对照、失败样本、约 5 名真实试用者反馈；效果有原始记录 |
| 4 工程与体验 | 与验证部分并行，约 3–5 天 | 异常恢复、存储、输入校验、视觉一致性、干净环境复现；3 条真实核心迭代链 |
| 5 参赛交付 | 争取 10 月底形成候选版 | 视频、PDF、远程仓库和证据逐项验收；11 月 18 日前留足缓冲 |

以上是目标节奏，不是已完成事实或无条件交付承诺。API、反馈和正式规则影响节奏；不以伪造数据或删减验证赶工。

## 技术与质量原则

优先使用成熟且易复现的 Web 技术栈。当前环境支持 React、TypeScript、Node.js 路线，选题后再确定数据库与求解依赖。

模型负责理解和提出候选；能精确计算的判断由程序执行。区分有界验证、经验发现与待确认结论。服务端保存密钥，校验输入，禁止直接执行模型生成的任意代码。

产品必须有完整数据流、状态保存、错误恢复和清楚的操作指引。演示数据与真实 API 显式区分；提供无密钥复现路径并单独验证真实模型路径。

只在有可测收益时加入多 Agent、3D、微服务等复杂性。原创集成、场景改进和算法首创分别表述，不把现成算法写成个人发明。

## 对照与证据

固定评价集后再优化，保留未参与调试的样例。对照当前人工流程、普通模型方案和拟建系统。记录检测准确性、漏报/误报、搜索或求解耗时、用户任务耗时、费用和失败案例。

开发过程同步保存真实提示、完整回复、代码差异、命令输出、修复和提交。不能在成品完成后编造三条过程链。

## 成本与协作

目前零付费。优先本地与免费依赖；小规模真实调用后按质量选择模型。人民币 30–100 元只是早期实验的规划额度，未查询报价、未发生支出，最终按实测调用量决定。

AI 负责研究、需求、设计、代码、调试、测试、技术说明和演示材料制作。用户无需手写代码，但需提供真实意图与反馈，确认匿名材料，完成本人报名/账号/支付操作，并逐步理解关键设计。真实试用和协作证据只能在实际发生后记录。
