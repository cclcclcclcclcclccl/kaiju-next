# v0.24：本轮搜索涉及的 74 位英雄基础教学卡

范围：上轮九组公开搜索结果标题中明确涉及的王者荣耀英雄，包含主讲英雄、对位对手和标题提及。排除其他游戏，以及“苍穹”“节奏大师”等误匹配。本轮完成 74 位英雄的官方文字研读与基础检查卡，不代表已完整观看 74 位英雄的 UP 主教学，也不代表全图鉴 133 位英雄均已完成专项研读。

## 网站中如何检查

1. 打开本地站点，在顶部搜索“教学”。
2. 展开“本轮搜索涉及英雄”，查看 74 位英雄的头像和覆盖状态；可按名称、分路查找。
3. 选择英雄，展开其专属卡片，查看决策要点、两个或以上检查问题、失效条件、专项练习与官方原文材料。
4. 查看“搜索中涉及该英雄的候选视频”。这些链接只代表公开标题收录，不是已研读或认可的视频结论。
5. 从英雄图鉴“我的打法”或录像复盘选择同一英雄，也能看到相应卡片；JSON 导出、个人训练卡和复盘包携带来源与版本边界。

## 资料冲突处理

11 位英雄有明确的旧提示或表述边界需要处理：刘备、宫本武藏、曹操、百里玄策、澜、司空震、心魔六耳、百里守约、鲁班大师、大乔、蔡文姬。

典型例子：蔡文姬旧团战提示写“大招清空敌方双抗”，而本次技能正文是治疗范围内最低血量友军并提供防御；鲁班大师的旧提示与当前页面机械飞索、强力收纳名称存在冲突；百里守约的旧“不暴击”建议不能直接当作当前装备依据。页面明确显示冲突，个人训练卡优先采用核对后的问题，已知冲突英雄的旧技能提示停止直接推荐、旧攻略摘录折叠展示。复盘协议要求模型不得把被否定的旧说法当成正面结论。

“本次技能正文”指本次取得的官网文本，不是已核验游戏客户端当前补丁。官方页面未提供明确的更新日期或统一版本号，仍需以游戏内技能与实际对局画面核对。定性检查卡是项目整理的练习问题，不是职业教练标注的正确答案。
