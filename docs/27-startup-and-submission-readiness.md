- `start-kaiju.cmd` / `npm run open` 调用后台启动器：检查Node版本、锁文件依赖和源码指纹，仅必要时安装/构建；健康检查通过后打开浏览器。重复启动复用正在运行的开局服务，其他服务占用端口时不强行终止它。

- 服务监听失败时清理刷新定时器，避免退出挂起。
- 本轮没有安装开机自启动或修改系统服务；电脑重启后双击启动文件。127.0.0.1仍仅本机可访问。
