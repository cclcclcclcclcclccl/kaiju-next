# 衡局 v0.1 架构与边界

## 闭环与数据流

React + TypeScript 界面编辑 Economy 模型 → API schema 校验 → 独立 Worker 内执行有界 BFS → 由独立 replay 函数验证见证 → SQLite 保存输入、结果、时间与 SHA-256 → 界面回放 / 导出 / 历史恢复。

文字建模是可选入口：用户显式点击 → 服务端读取配置 → 发送原始输入与固定提示 → 严格候选校验和引文存在检查 → 用户确认 → 进入同一验证流程。模型不会生成并执行任意代码。

## 搜索为什么能返回短反例

状态包含所有已定义资源的整数库存。动作合法性只取决于当前库存；相同状态的较长到达路径不会增加后续可达性，因此可以去重。按路径长度进行广度优先搜索，第一次遇到违反约束的状态给出当前模型的最短见证。

如果将来加入冷却、一次性奖励、回合数或隐藏标记，这些信息必须进入状态键，否则原有去重逻辑不再可靠。当前没有假称支持这些特性。

独立穷举测试不复用搜索函数的状态扩展逻辑，用于交叉核对小规模情况下的检测和最短长度。

## 结论含义

- counterexample：得到一条合法操作序列，指定库存恢复初值且观察资源净增超过允许值。
- bounded-clear：在给定初始状态、动作模型和搜索深度内，没有找到反例。
- inconclusive：触及状态或时间预算，不能给出范围内无反例结论。

这项契约不是所有游戏的通用合理性标准。制造盈利可能是设计目标，因此必须先确认设计意图。

## 修改候选

统计反例中各动作出现次数，尝试减少目标资源产出或增加目标资源成本，使旧路径净增不再超限。每个候选都重放旧路径并重新搜索。候选可能仍有其他反例，界面按实际结果显示。

没有进行全局最小修复证明，也没有优化玩家体验、收益节奏、胜率或多目标平衡。

## 本机服务边界

服务默认只绑定 127.0.0.1。检查 Host 与浏览器 Origin，不开放跨域；请求正文限制 128 KB；搜索同时最多两个任务；Worker 有 128 MB 老生代限制和超时。SQLite 使用参数化 SQL。静态文件路径限制在 dist 中。

这是本机工具，尚未提供公网部署所需的多用户身份认证、访问控制、限流隔离、备份或运维策略。不能直接将服务绑定公网并声称生产安全。

## 模型适配的实际状态

兼容 chat/completions，限制输入长度和响应体积，显式超时，服务端保管密钥。候选每个数值需要对应输入原文，缺信息要求澄清。

协议已通过本机模拟模型服务测试；未接入商业模型做真实效果评测。输入中存在引用不等于语义完全正确，用户确认步骤仍不可省略。

## 验证覆盖和缺口

已验证：核心契约、最短路径、修改候选、初始库存误报控制、非法输入、资源预算、实际 API、快照、导入导出、历史恢复、草稿、手机布局、主要状态的自动可访问性检查。

未验证：真实用户有效性、商业模型表现、大规模复杂经济、长时间压力、所有浏览器、完整无障碍标准、干净操作系统部署、竞赛官方最新要求。示例全部为合成，不是已有商业游戏漏洞披露。

## 依赖来源

界面使用 React、Vite 和 TypeScript；图标使用 Lucide；输入校验使用 Zod；浏览器测试使用 Playwright 与 axe-core；SQLite 来自 Node.js。没有复制完整开源应用或使用外部游戏素材。精确版本由 package-lock.json 锁定，各依赖沿用自身许可证。


## v0.2 补充：保留设计意图与独立凭证

Economy 的可选 playtests 字段最多 8 条，每条为独立初始库存覆盖、最多 32 步动作 ID 序列、期末最低库存要求。省略初始库存键表示继承主规则；minimum 是绝对期末数量，不是净增。旧版本模型与历史记录仍可读取。

共享 simulation.ts 负责单步状态、反例回放和保留检查，可在浏览器给编辑者实时反馈，并由服务端在保存正式实验和比较修复时重新执行。返回 pass、blocked（明确失败步骤）或 below-minimum。前后对照区分“新破坏”与“基线本就失败”。不满足声明的保留要求时 UI 禁止直接载入；没有用例时明确未评估玩法影响。

资源与动作编辑器在保存时使用相同 schema，移除有依赖的资源或动作时提示修改依赖，不静默删掉用例。恢复库存可视选择，未受约束资源在输入和结果中说明。模型候选展示具体数值与规则预览；模型不能自行声明保留用例，由设计者在确认后添加。

Run 保存引擎版本与保留结果，旧记录缺失这些字段不伪装为已评估。实验凭证格式 hengju-evidence/1 包含独立快照，scripts/verify-evidence.mjs 可验证指纹、重放路径、复查保留结果和同界限搜索。不把 SHA-256 视为作者签名，不复现时间依赖的状态计数。

语义相同的对象属性顺序不再导致结果误判为过期；动作/资源数组顺序仍保留其意义。浏览器草稿保存搜索范围与项目关联，连续撤销保留最近 30 次编辑快照。
