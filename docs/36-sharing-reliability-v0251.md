# 分享可靠性改进 · v0.25.1

本轮优先解决同学共同使用的真实问题，未修改梯度数值、BP 强度权重或宣称新增模型训练。

## 已修复

1. 原登录限流取回环代理的 IP，所有公网用户共用每分钟 20 次额度。现由显式配置的本机 Cloudflare/Caddy 代理提供真实访问者地址，直连默认不信任转发请求头；每个网络地址每分钟最多 60 次、每账号每分钟 20 次，限制只在当前应用实例内生效，过期记录回收。返回明确 Retry-After 和中文重试时间。共享同一公网 IP 的校园用户仍共用网络额度，不能宣称每个人都具有独立 IP。
2. 公网断线提示改为检查网络、联系分享者和核对链接；不再要求同学运行开发机上的脚本。连接恢复保留当前输入，不自动重复提交；首次页面加载因断网失败后支持恢复加载。
3. 网关返回 HTML 错误或网络请求中断时，显示可读中文。保存中断不能证明服务端没有保存，因此提示先核对已保存记录，不能显示虚假的“保存成功”或自动重复写入。
4. 分享页面增加复制网址，剪贴板不可用时提供可手动复制的地址；明确临时地址在线条件。
5. 新增 SQLite 在线一致性备份，包含已提交 WAL 数据，检查 integrity_check 并生成 SHA-256 报告。拒绝覆盖源库或既有备份。双击 `backup-public.cmd` 或运行 `npm run backup:public`，备份保存在 `data/public-site/backups/`，不是公开附件。
6. 准备固定域名、Caddy HTTPS、systemd 开机启动及每日备份配置，见 `deploy/README.md`。这些是待部署配置，不是已完成的云端托管。
