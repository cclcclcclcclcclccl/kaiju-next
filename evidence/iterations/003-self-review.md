## 自审发现与完成的修改

1. 修复验证只保护“不得套利”的要求，没有保护正常玩法。新增可编辑的保留用例，独立起点、顺序动作、最低期末库存；正式实验与候选比较在服务端再次执行。默认示例显示售价 7→6 可保留新手首次制造，矿价 3→4 会让 6 金币新手卡在第二次购买。该方案不能直接载入。
2. 自定义规则依赖手写 JSON。新增资源/标题/说明编辑器，支持多资源成本与产出矩阵；删除前检查用例与动作依赖。
3. 恢复库存只选部分资源时，读者可能误当成完整闭合套利。增加可视选择以及输入、结果、报告的范围说明。
4. AI 候选原本只有引文，缺少完整模型数值预览。增加初始库存、动作、约束、数值和引文对照，需勾选语义核对；生成期间锁定原文，服务端拒绝模型擅自添加保留用例。
5. 报告指纹不能独立复现。补全报告的模型与边界输入，增加实验凭证和独立 Node 核验工具，支持规则指纹、轨迹、保留检查及同范围复搜。凭证导入只导入输入，结果须重新计算。
6. 草稿不记搜索范围/项目 ID、撤销只能切换最后两版。保存这些元数据，改为最多 30 次连续撤销；非法数值恢复时提供明确反馈。
7. 用户不清楚赛题与产品，说明沟通与上手材料不足。增加 docs/07-first-review-guide.md，解释比赛、选题、账本示例、AI 与确定性计算的分工、十步检查路线及未完成项。

## 验收中实际发现的 Bug

第一次 11 项浏览器测试中，9 项通过、2 项失败：“比较修复方案”一直禁用。定位到 schema 输出将 playtests 放在 contract 之前，而内置示例顺序相反；原逻辑直接比较 JSON 字符串，误判无修改规则为过期。

修复为忽略对象键顺序的模型语义比较，保留数组顺序。复跑 11 项全部通过。这是真实验收发现的故障，不是故意制造的演示。首次执行工具脚本还出现一次 JavaScript 模板字符串嵌套语法错误，未产生文件修改，重写后执行。

服务更新时，已核对的 Node 进程停止后其 Path 属性变空，首次重启命令失败；随后通过 Get-Command node 获取实际可执行路径，隐藏启动成功。现场地址确认 v0.2.0、运行与比较正常、无浏览器脚本错误。
