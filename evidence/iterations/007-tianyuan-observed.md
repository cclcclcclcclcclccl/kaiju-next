# 007 · 实际进入天元之弈与统计口径修正

2026-10-12，v0.6.0。用户回复“已打开，窗口保持可见”并要求继续。本记录为开发摘要，不替代完整原始对话。

用户打开微信小程序后，检测到标题“天元之弈助手”的窗口。初次 PrintWindow 返回空黑图；随后发现最小化与 DPI 坐标差异。恢复目标窗口、启用 DPI 感知后，只截取该窗口范围，成功查看数据、梯度、英雄详情、工具与战力页。未发送消息，未上传个人文件或读取微信聊天。

实际发现：数据页的千强定义为 QQ 双区各分路约 1000 名选手；说明胜率按版本滚动累计，胜率全量样本含更低分段。英雄页有趋势、调整标记、带场次的克制/组合。工具页已有 OCR 版 BP 截图推荐，因此“AI 推荐英雄”不能单独作为差异化主张。战力工具只核对可见示例，没有得到完整分段公式。

实际修改：新增胜率人群/时间/选禁分母/口径备注；不明或混合口径退出梯度、区间和 BP 分；未知分母不相加。增加有来源的同口径历史对比、百分点变化、交互指标、原始表格、多英雄搜索和低出场率筛选。历史不跨版本/来源/分段，不编造日期，提示区间重叠。旧批次缺字段时保留数据但默认待核对。

根据可见截图逐项转录海月、鲁班大师、盾山、少司缘共四位真实指标，保留原始显示精度和缺失字段，作为局部人工观察快照导入本机访客工作台。没有替换既有数据、没有虚构场次或完整榜单。海月实际页面经只读浏览器核对，正确显示原始数值与“口径待核对”。样例 JSON 和转录证据清单一并保存。

审查中发现原 BP 只排除“样本不足”“待验证”，新增“口径待核对”也会漏入。改为仅正式 T0–T4 启用，测试覆盖大量场次也无法越过口径门槛。

自动审批拒绝了新增测试的全量快照清理，理由为可能删除用户数据。改为每个新增测试独立注册账号，不再执行该删除；实际测试仍运行独立 4319 服务和隔离数据库。无须批准广范围删除。原生禁用 option 的测试断言第一次失败，按实际 DOM 改为检查 disabled 原生属性后通过。

验证：24 核心/接口，17 完整浏览器，构建和格式检查通过；手机图表文字调整后额外复核新增 2 流程通过。11 状态 axe 无检出违规，存在人工判断项。实际 v0.6 五个只读页面状态无脚本错误/溢出/失败请求；没有向个人库导入合成统计。
